# ALLTIME GOLF（オルタイムゴルフ）

オンラインゴルフレッスンの会員サイトです。

- **`app/`**: 本番用の会員サイト（Supabase + Stripe + YouTube 限定公開リンク）
  - 会員：ログイン、月額プランの申し込み、動画提出、レッスン・課題の確認、契約管理
  - 管理者（コーチ）：提出動画の確認、レッスン作成、会員情報・練習課題の編集
- **`index.html`**: スクール紹介ページ（トップページ）。連絡先はファイル内の `CONTACT` を書き換えると反映
- **`prototype/`**: 初期の試作品（データはブラウザ内に保存）

セットアップ手順は [docs/SETUP.md](docs/SETUP.md) を参照してください。
