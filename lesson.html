How It Works

レッスンとアプリの使い方

スマートフォンでスイングを撮って送ると、PGAプロのレッスンが届きます。はじめるまでの流れと、会員ページの使い方をご紹介します。

Before You Start

はじめるまで

お問い合わせから、最初のレッスンまでの流れです。

  1. LINE・お電話で相談

    まずはお気軽にご連絡ください。レベルや目標をうかがい、合うプランをご案内します。

  2. プランを決める

    レベルや目標に合わせて、プランをお選びいただきます。サブスクリプション制は、初回カウンセリングで今のスイングをチェックします。

  3. 会員ページに登録

    プランが決まったら、会員ページ（アプリ）に登録。最初のログインで使い方ガイドが表示されます。

  4. レッスンスタート

    スイング動画を撮って送るところから、レッスンが始まります。

用意するもの
  • スマートフォン（会員ページも撮影も、スマートフォンだけで使えます）
  • スマートフォンを置く台や三脚（なくても撮れますが、あると安定します）
  • スイングできる練習場所（練習場など）

Lesson Flow

レッスンの流れ

「撮る → 送る → 届く → 練習する」をくり返しながら、一つずつ課題をクリアしていきます。

STEP1あなた

スイングを撮る

  1. 会員ページの「撮影・提出」から、撮影機能「SwingFrame」を開きます
  2. 画面の人型のガイドに体が入るようにスマートフォンを置き、録画ボタンで撮影します
  3. 「自動録画」にすると、構えたら録画が始まり、打球音のあとに自動で止まります
  4. 撮った動画は、スロー・コマ送り・線を引く・前の動画と並べて比べる、まで手元で確かめられます
きれいに撮るコツ
  • 正面（体の正面）または後方（打つ方向の後ろ）から撮る
  • 頭から足先まで、クラブ全体が画面に入るようにする
  • スマートフォンは胸の少し下あたりの高さで固定する

STEP2あなた

動画をコーチに送る

  1. 撮った動画の再生画面で「⛳ コーチへ」を押すと、提出画面にそのまま届きます（スマートフォンに保存してある動画も選べます）
  2. 使ったクラブ・撮った方向・今の悩みや質問を書いて、「動画を送信する」を押します
  3. 送れる本数は、プランごとに毎月決まっています。残りの回数はマイページでいつでも確認できます
送った動画について送った動画は3か月間、履歴から見返せます（その後は自動で削除されます）。

STEP3コーチ

レッスン（解説）が届く

  1. PGAプロが動画をチェックし、課題と練習法をまとめたレッスンをお届けします
  2. レッスンが届くとメールでお知らせが届き、会員ページに NEW の印が付きます
  3. 今回の診断・解説動画・フィードバック・次回までの練習が、1つのページにまとまっています
  4. わからない言葉は、レッスンの画面からそのまま「用語集」で調べられます

STEP4あなた

練習する・記録する

  1. マイページの「今月の練習」に、今月のドリルとレッスンの練習メニューがまとまって表示されます
  2. 練習が終わったメニューは、タップしてチェックします
  3. 練習した日はボタンひとつで記録。カレンダーで1か月分の練習日を確かめられ、付け忘れた日もあとから記録できます
  4. コーチから個別の課題が出たときも、ここに表示されます

STEP5あなた

オンライン面談で相談する

  1. マイページの「LINEで面談を予約する」から、日程を予約します
  2. ビデオ通話で、PGAプロと直接お話しできます。ドリルを画面で共有しながら解説します
  3. 悩み相談・進み具合の確認・これからの課題を、一緒に整理します
  4. 面談の回数はプランによって異なります（サブスクリプション制は月1回25分、ユーキャン制は年4回程度）

STEP6あなた

ふり返って、また撮る

  1. 送った動画と解説は、履歴にセットで残ります
  2. SwingFrame の「比較」で、前の動画と今の動画を並べて、変わったところを確かめられます
  3. 練習の成果が出たら、また撮って送りましょう。新しい課題の質問も一緒にどうぞ

App Features

そのほかの便利な機能

毎日の練習が続くように、会員ページにはこんな機能もそろっています。

毎月のドリル・1年間の練習計画

今月やることが、毎月届きます。

  • 初回のカウンセリングをもとに、あなた専用の1年間の練習計画（ロードマップ）をつくります
  • 毎月1つ、テーマと練習ドリルが公開されます
  • レッスンで届いたドリルも、ここにたまっていつでも見返せます

  • 用語集

    レッスンに出てくるゴルフの言葉を、やさしく解説。ルールやマナー、安全のことも調べられます。

  • メモ

    練習で気づいたことを書いておけます。ホームにいちばん新しいメモが表示されます。

  • スコア記録

    ラウンドのスコアを記録すると、ベストスコアと平均スコアを自動で計算します。

  • お知らせ

    アプリの新しい機能やお知らせは、ログインしたときにお届けします。

  • レッスンのお知らせメール

    レッスンが届いたときに、メールでお知らせします。届くメールは設定で選べます。

  • 不具合・ご要望

    使いにくいところや、あったらうれしい機能は、アプリからそのまま送れます。

※ 画面はイメージです。内容はプランによって異なる場合があります。

Q&A

よくある質問

ゴルフ初心者でも受講できますか？

はい。初心者〜初級者の方には、カリキュラムを順番に進める「ユーキャン制」がおすすめです。

撮影にはどんな機材が必要ですか？

スマートフォンがあれば大丈夫です。撮影の条件（方向・距離など）は課題ごとにご案内します。

面談はどのように行いますか？

オンラインで行います。ドリルを画面で共有しながら、PGAプロが解説します（サブスクリプション制は月1回25分、ユーキャン制は年4回程度）。
