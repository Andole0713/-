How It Works

レッスンとアプリの使い方

スマホで撮ったスイング動画をPGAプロが添削。オンライン面談や毎月のドリルで上達していきます。はじめるまでの流れと、会員ページの使い方をご紹介します。

Before You Start

はじめるまで

お問い合わせから、最初のレッスンまでの流れです。

  1. LINE・お電話で相談

    まずはお気軽にご連絡ください。レベルや目標をうかがい、合うプランをご案内します。

  2. プランを決める

    レベルや目標に合わせて、プラン（サブスクリプション制はコースも）をお選びいただきます。サブスクリプション制は、初回カウンセリングで今のスイングをチェックします。

  3. 会員ページに登録

    プランが決まったら、会員ページ（アプリ）に登録。最初のログインで使い方ガイドが表示されます。

  4. レッスンスタート

    スイング動画を撮って送るところから始まります（最初の面談で担当プロが作ったロードマップのドリルも届きます）。

用意するもの
  • スマートフォン（会員ページも撮影も、スマートフォンだけで使えます）
  • スマートフォンを置く台や三脚（なくても撮れますが、あると安定します）
  • スイングできる練習場所（練習場など）

Lesson Flow

レッスンの流れ

「撮る → 送る → 添削が届く → 練習する」をくり返しながら、オンライン面談で課題を整理していきます。
サブスクリプション制はオンライン面談、12か月上達プログラムは年間の課題とドリルが中心です。

STEP1あなた

スイングを撮る

  1. 会員ページの「撮影・提出」から、撮影機能「SwingFrame」を開きます
  2. 撮る向きは「正面」か「後方（目標方向の後方線上）」のどちらかです
  3. 画面の人型のガイドに体が入るようにスマートフォンを置き、録画ボタンで撮影します。「自動録画」にすると、構えたら始まり、打球音のあとに自動で止まります
  4. スロー・コマ送り・線を引く・前の動画と並べて比べる、まで手元で確かめられます
撮影の向き（この2つだけ）
  • 正面：体の正面（おなか側）から
  • 後方：目標方向の後方線上（打つ方向の真後ろ）から
  • 頭から足先まで、クラブ全体が画面に入るように。スマートフォンは胸の少し下あたりの高さで固定します

STEP2あなた

動画をプロに送る

  1. 撮った動画の再生画面で「⛳ コーチへ」を押すと、提出画面にそのまま届きます（スマートフォンに保存してある動画も選べます）
  2. 使ったクラブ・撮った向き・今の悩みや質問を書いて、「動画を送信する」を押します
  3. 送れる本数は、プラン・コースごとに毎月決まっています。残りの回数はマイページでいつでも確認できます
送った動画について送った動画は3か月間、履歴から見返せます（その後は自動で削除されます）。残しておきたい動画は「☆ お気に入り」にすると、3つまで消えずに残せます。

STEP3コーチ

添削（レッスン）が届く

  1. プロが動画に線を引いて課題をチェックし、解説と練習法をまとめたレッスンをお届けします
  2. レッスンが届くとメールでお知らせが届き、会員ページに NEW の印が付きます
  3. 診断・解説動画・フィードバック・次回までの練習が1つのページにまとまり、送った動画とセットで履歴に残ります
  4. わからない言葉は、レッスンの画面からそのまま「用語集」で調べられます

STEP4あなた

練習する・記録する

  1. マイページの「今月の練習」に、レッスンの練習メニューがまとまって表示されます
  2. 最初の面談で担当プロが決めた3・6・12か月の目標に沿って、ロードマップで毎月ドリルが公開されます
  3. サブスクリプション制は面談で達成状況を確認しながらドリルを選び直し、12か月上達プログラムは毎月の課題動画と練習ドリルで年間のカリキュラムを進めます
  4. 練習した日は「✓ 今日練習した」を押すだけで記録。カレンダーで1か月分を確かめられ、付け忘れた日もあとから記録できます
  5. 練習の記録はプロにも届き、添削や面談に活かされます

STEP5あなた

オンライン面談で相談する

  1. Zoomのようなビデオ通話で、画面越しにPGAプロと直接お話しできます
  2. サブスクリプション制は、この面談が中心です（コースにより毎月1〜2回）。12か月上達プログラムはオプション（年4回程度がおすすめ）です
  3. 最初の面談とロードマップづくりは担当のPGAプロ、その後は手の空いているプロ・コーチが対応します。指導の内容はカルテで共有しているので、一から説明し直す必要はありません
  4. 動画やドリルを画面で共有しながら、悩み相談・進み具合の確認・これからの課題を一緒に整理します
  5. 日程はマイページの「LINEで面談を予約する」から予約します。面談のまとめはマイページで見返せます

App Features

そのほかの便利な機能

毎日の練習が続くように、会員ページにはこんな機能もそろっています。

履歴・ふり返り

これまでの歩みが、すべて残ります。

  • 送った動画とプロの解説が、セットで月ごとに並びます
  • SwingFrame の「比較」で、前の動画と今の動画を並べて、変わったところを確かめられます
  • これまでのドリルもたまっていくので、いつでも見返せます

  • 用語集

    レッスンに出てくるゴルフの言葉を、やさしく解説。ルールやマナー、安全のことも調べられます。

  • メモ

    練習で気づいたことを書いておけます。ホームにいちばん新しいメモが表示されます。

  • スコア記録

    ラウンドのスコアを記録すると、ベストスコアと平均スコアを自動で計算します。

  • お知らせ

    アプリの新しい機能やお知らせは、ログインしたときにお届けします。

  • レッスンのお知らせメール

    レッスンが届いたときに、メールでお知らせします。届くメールは設定で選べます。

  • 不具合・ご要望

    使いにくいところや、あったらうれしい機能は、アプリからそのまま送れます。

Q&A

よくある質問

「毎月のドリル」とは何ですか？

上達のための練習メニュー（動画つき）です。最初の面談で担当プロが決めた3・6・12か月の目標に沿って、毎月ロードマップで公開されます。サブスクリプション制は面談で達成状況を確認しながら選び直し、12か月上達プログラムは年間のカリキュラムに沿って進みます。

ゴルフ初心者でも受講できますか？

はい。ゴルフを始めたばかりの方も受講いただけます。今のレベルや目標をうかがって、合うプランをご案内します。

撮影にはどんな機材が必要ですか？

スマートフォンがあれば大丈夫です。撮影の条件（方向・距離など）は課題ごとにご案内します。

面談はどのように行いますか？

Zoomのようなビデオ通話で、画面越しにPGAプロと直接お話しします。動画やドリルを画面で共有しながら解説します（サブスクリプション制はコースにより月1〜2回、12か月上達プログラムはオプションで年4回程度がおすすめ）。

担当のプロは毎回同じですか？

最初の面談とロードマップづくりは、担当のPGAプロが行います。その後の添削や面談は、手の空いているプロ・コーチが対応します。指導の内容はカルテで共有しているので、毎回一から説明し直す必要はありません。
